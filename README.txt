PRINTCALC – Installation
1. ZIP entpacken. Alle Dateien zusammen in einen HTTPS-Webspace hochladen, z. B. GitHub Pages.
2. GitHub: neues öffentliches Repository erstellen, die sechs App-Dateien (index.html, manifest.json, sw.js, icon-192.png, icon-512.png; README optional) direkt in dessen Hauptverzeichnis hochladen.
3. Settings > Pages > Deploy from a branch > main / (root) > Save. Die angezeigte Pages-URL öffnen.
4. Auf dem iPhone in Safari: Teilen > Zum Home-Bildschirm > Hinzufügen.
5. App einmal mit Internet öffnen, damit alle Offline-Dateien gecacht werden.

Die HTML-Datei kann auch direkt am PC geöffnet werden. Installation und Service Worker benötigen HTTPS (oder localhost). Gespeicherte Daten sind lokal und können durch Löschen der Browserdaten verloren gehen. CSV-Export als Sicherung verwenden.
